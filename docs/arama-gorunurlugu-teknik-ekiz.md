# Arama Görünürlüğü — Teknik Kontrol (Ekiz)

İşletme sahibine giden sade metin:  
[isletme-sahibi-google-gorunurluk.md](./isletme-sahibi-google-gorunurluk.md)

Bu dosya sizin düzenli teknik kontrol listenizdir. Site haritası, robots, Search Console vb. burada kalır; müşteriye gönderilmez.

---

## Ölçüm

### Search Console (haftalık / aylık)
- Kapsam / indeks sorunları
- Performans: sorgu, tıklama, gösterim, CTR, ortalama konum
- Yükselen / düşen sayfalar
- Sitemap gönderimi ve hata durumu
- Manuel işlem / güvenlik uyarısı

### Analytics
- Organik oturum trendi
- Dönüşüm: form, `tel:`, WhatsApp
- Landing page performansı
- Organik → lead oranı (aylık)

### Core Web Vitals (çeyreklik veya deploy sonrası)
- Mobil LCP, INP, CLS
- Görsel, font, üçüncü parti script yükü

---

## Teknik SEO

| Madde | Kontrol |
|-------|---------|
| HTTPS | Sertifika, mixed content |
| robots.txt | Önemli sayfalar engelli mi |
| XML sitemap | Güncel mi, GSC’de hata var mı |
| Canonical | Çift URL / parametre |
| Title / description | Önemli sayfalarda benzersiz |
| H1 / başlık yapısı | Anlaşılır hiyerarşi |
| İç linkler | Para / hizmet sayfalarına güç |
| 404 / kırık link | Crawl + UX |
| 301 yönlendirmeler | Eski → yeni |
| Structured data | LocalBusiness / Organization / FAQ |
| hreflang | Çok dilli ise |

---

## İçerik (teknik taraf)

- Thin / duplicate audit: tut / güncelle / kaldır / birleştir
- GSC sorgularından fırsat → sayfa güncellemesi
- Site genelinde ince içerik oranı yüksekse önce temizlik
- Yayın öncesi: niyet, unikalite, E-E-A-T

**Kaynaklar:**  
[SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) · [Helpful content](https://developers.google.com/search/docs/fundamentals/creating-helpful-content) · [Spam policies](https://developers.google.com/search/docs/essentials/spam-policies)

## Yerel

- GBP: kategori, hizmet alanı, foto, saat
- NAP audit: site, schema, GBP, Bing Places, dizinler
